⚠️ Data Recovery Instructions

If data was lost:
  1. Check the "Available Backups" section above
  2. Find the backup from before the data loss
  3. Click "Restore" on that backup
  4. The database will be restored to that point in time

Note: Restoring a backup will replace the current database. Make sure to create a backup of the current database first if you want to keep it.
